Conversor de remessa CNAB240 para CNAB400 Vórtx

Converte um arquivo de remessa CNAB240 no padrão FEBRABAN (segmentos P, Q e R) para o layout CNAB400 da Vórtx, banco 310, versão 1.1. O arquivo é processado no seu navegador e não é enviado para nenhum servidor.

Conta do beneficiário

Se ficar vazio, usa a conta do beneficiário sem o dígito.

Remessa

Nunca pode se repetir. Incremente a cada arquivo enviado.

O registro 1 da Vórtx não tem campo de bairro, cidade ou UF.

Resultado

Escolha um arquivo CNAB240 e preencha os dados da conta para gerar a remessa CNAB400.

Prévia do arquivo gerado

Passe o cursor sobre um trecho para ver o campo e suas posições. Clique numa linha para ver todos os campos do registro.

Layout de referência: Grafeno Vórtx CNAB 400, Remessa v1.1. Gera os registros 0, 1, 2 e 9; split (3) e sacador com endereço (7) não são gerados.
